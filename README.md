# cmux skill for Claude Code

A single SKILL.md that teaches Claude Code to drive the [cmux](https://github.com/manaflow-ai/cmux) terminal: spawn visible worker agents, monitor them, report sidebar progress, and preview work in browser panes — merged from the official manaflow-ai skills plus the best community cmux skills.

## Install

```bash
curl -fsSL --create-dirs -o ~/.claude/skills/cmux/SKILL.md \
  https://github.com/flow-brandon/cmux-skill/releases/latest/download/SKILL.md
```

Or copy `skills/cmux/` into your repo.
